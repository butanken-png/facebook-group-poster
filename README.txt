Facebook Group Poster V3.2

Cài đặt:
npm install
npm start

Đóng gói Windows:
npm run dist

V3.2:
- Calendar theo tháng.
- Kéo thả lịch sang ngày khác.
- Click ngày xem chi tiết từng bài, giờ, trạng thái và nhóm.
- Điều hướng tháng trước / tháng sau / hôm nay.
- Giữ dữ liệu V3.1 qua localStorage.
- Xuất dữ liệu JSON V3.2.

Lưu ý: lịch chạy cục bộ và ứng dụng cần mở tại thời điểm lịch chạy. Ứng dụng không tự bấm Đăng trên Facebook.
